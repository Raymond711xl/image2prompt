# GPT Image 2 提示词规范

## 核心特点

- **指令遵循极强**：空间关系、数量、占比、文字内容写得越明确执行越准——"左侧""三个""占画面上方 1/3"这类硬约束可以放心写死，它会照做。这是与国产模型写法的最大差异：国产版靠氛围描述，GPT Image 2 版可以下精确指令。
- **两种模式**：垫图编辑（上传参考图 + 修改指令，改局部保整体）和文生图（纯描述从头生成）。
- **文字渲染强**：英文文字最稳，中文短语可用。画面文字用引号标注，并指定位置和字体风格。
- **语言**：中文提示词理解很好，默认用中文写（方便用户自己微调）；用户要求或需要更精准的风格控制时给英文版。

## 垫图编辑公式（换主体、改局部首选）

**保留锚点 + 修改目标 + 融合要求**

- 保留锚点：明确说保持什么不变（构图、光线方向、色调、背景、透视）。不写锚点，模型可能连不该动的地方一起重画。
- 修改目标：把 X 换成 Y。Y 的外观描述要具体：材质、颜色、朝向、比例。
- 融合要求：新元素要匹配原图光影和透视，接触面的阴影、反射自然。这一句决定成品像不像"P 上去的"。

要点：一次一件事，多处改动拆成多轮指令；消除原品牌痕迹要明说；需要保持人物或产品一致时写"面部和姿态保持完全一致"。

## 边界控制（局部编辑防溢出，实测教训）

编辑模型有"主题一致化"倾向：大面积替换品牌/风格后，它会把画面里相似的元素全部和谐成同一主题（邻居展位跟着换牌、无关屏幕跟着换内容），还可能无中生有补充"符合主题"的新物体。写局部编辑指令时四条纪律：

1. **指令第一句先圈范围**：用看得见的视觉锚点定义编辑区（"仅限画面中央偏右、带深灰色悬浮顶棚的那一个展位"），不要用模型看不见产权的概念词（"展位内""我们的区域"）。
2. **保护清单和修改清单同等重要**：显式列出"保持与原图完全一致"的元素，并点名它们的原有内容（"右侧粉色的农产品供应链灯箱保持原样"）——点名原内容等于把它锚死。
3. **枚举替换目标，禁用"所有/全部"**：量词会扫射到边界外。"该展位正面两块大屏 + 右侧双面灯箱"好于"所有大屏灯箱"。
4. **加禁增条款**："只替换点名的元素，不新增任何原图中不存在的物体，不删除未点名的元素。"

语言边界永远是软的。要求更硬时：平台支持涂选区域（局部重绘/inpainting）就先框住目标再下指令；或分轮编辑一次只动一个区域；提案场景还可以后期拼合——用原图做底，只把生成图中改对的区域抠回去。

## 文生图写法

比国产模型更耐受长描述和叙述式写法。元素之间的关系直接写明（"咖啡机在画面右侧，一只手从左侧伸入"），构图、留白、文字位置都可以用精确比例约束。

## 范例

**换主体（垫图编辑）**

```
保持原图的构图、光线方向和背景完全不变，将台面上的香水瓶替换为一台奶白色胶囊咖啡机，咖啡机的受光面与原图光源方向一致，在台面上留下柔和的接触阴影，去除画面中原有的品牌文字
```

**Hero shot（文生图）**

```
商业产品摄影：一台奶白色胶囊咖啡机置于哑光石材台面中央偏右，占画面高度约一半。左侧柔光箱侧光勾勒机身轮廓，背景是暖灰色渐变影棚背景，无其他物体。低饱和暖色调，画面干净克制，8K 细节
```

**情绪海报（文生图，带画面文字）**

```
极简主义竖版海报：一只登山靴立于云海之上的岩石尖端，位于画面下方 1/3 处，上方 2/3 为干净的天空留白。晨曦金色侧逆光，冷蓝与金色对比色调。画面上方 1/4 处居中排版无衬线标题文字"走得更远"，白色细体
```
