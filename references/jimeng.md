# 即梦 / 豆包 / 可灵：中文文生图提示词规范

## 基本公式

风格媒介 + 景别视角 + 主体（外观细节）+ 动作状态 + 场景环境 + 光线 + 色调 + 氛围 + 画质词

自然语言连贯书写，逗号分层。先重后轻：模型对开头的权重更高，把最重要的信息（风格 + 主体）放最前面。

## 写作要点

- **具体压倒抽象**："哑光黑色保温杯，杯身凝着水珠" 远好于 "一个高级的杯子"。形容词要能被"画出来"。
- **镜头语言直接有效**：特写/中景/全景、俯拍/仰拍/平视、浅景深背景虚化、微距、长焦压缩感。这些词模型理解得很好。
- **光线是广告感的核心**：写明方向和软硬——柔光箱侧光、黄昏逆光、窗边自然光、影棚顶光。一句到位的光线描述比三个画质词都管用。
- **画质词点到为止**（1-2 个）：商业摄影、8K 细节、超写实。堆砌不会更清晰，只会稀释权重。
- **画面文字**：即梦系对中文渲染较好。需要文字时用引号标注：画面上方标题文字"焕新一夏"，无衬线字体。
- **用正向表述规避负向内容**：想要干净背景写"纯色极简背景"，而不是"没有杂物"——模型对否定词不敏感。
- **画幅比例在平台界面选择**，但构图意图要写进提示词：竖版海报构图，主体位于下三分之一，上方留白。

## 范例

**产品广告（hero shot）**

```
商业产品摄影，特写平视，一台奶白色胶囊咖啡机置于哑光石材台面上，机身流线光滑带柔和高光，背景为暖灰色渐变影棚背景，左侧柔光箱侧光勾勒轮廓，右侧微弱补光，低饱和暖色调，画面干净克制，高级质感，8K细节
```

**场景化 lifestyle**

```
生活方式摄影，中景微俯视角，年轻女性在晨光洒落的原木餐桌旁双手捧着一杯热拿铁，胶囊咖啡机在背景中虚化可见，窗边自然光柔和逆光，暖黄色调，浅景深，慵懒惬意的周末清晨氛围，真实生活质感
```

**情绪海报**

```
极简主义海报摄影，竖版全景构图，一只登山靴立于云海之上的岩石尖端，晨曦金色侧逆光，大面积天空留白占据画面上方三分之二，冷蓝与金色对比色调，孤高辽阔的氛围，商业广告级画质
```
