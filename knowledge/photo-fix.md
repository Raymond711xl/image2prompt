# 照片优化固定指令（模式 B 用）

## 使用方法

1. **先诊断**：对着图把问题列具体（哪里歪、哪块暗、偏什么色、糊在哪、什么杂物），写进输出的"问题诊断"清单。诊断决定下面模板保留哪些条目——图不歪就删矫正条，色准就删白平衡条。
2. **主观决定问用户**：景别裁切、色调取向、保留与强调三类是用户的审美和用途决定的，不要替用户做主（详见 SKILL.md 模式 B 第 2 步）。尤其裁切——用户拍全景常常就是要看全貌，默认**不裁切**，只有用户点头才收紧构图。
3. 从基础指令起步，删掉不适用的条目，把诊断出的问题和用户的决定改写成针对性描述（"提亮欠曝暗部"→"提亮左侧背光的人物面部"）。
4. **垫原图使用**：GPT Image 2 上传原图 + 指令；即梦/豆包的图生图（智能参考）用同一条指令。此类任务不出文生图版——重画会丢掉照片里的真实内容。

## 基础修图指令（固定模板）

```
在完全保留画面内容、人物姿态和物体位置不变的前提下，对这张照片做专业后期优化：
1. 矫正水平线和透视畸变，让垂直线条恢复垂直、画面横平竖直
2. 平衡整体曝光：提亮欠曝的暗部细节，压回过曝的高光，保留自然明暗层次
3. 校正白平衡至准确中性，消除偏色
4. 适度提升清晰度和锐度，消除轻微模糊和手抖痕迹，降低噪点
5. 色彩饱和度和通透度自然提升，鲜活但不过艳
6. 整体呈现专业摄影后期的干净质感，不要过度磨皮、不要HDR感
```

## 常见追加条目（按诊断选用）

- **仅矫正不裁切**（用户要保全景时的默认）：`保持原始构图和完整视野，不裁切、不改变景别，仅做几何矫正`
- **构图裁切**（仅在用户确认后用）：`裁切为[4:3/16:9/3:4]画幅，让[主体]位于[居中/三分位]，去除边缘无关区域`
- **顽固偏色**（实测：笼统说"校正白平衡"力度不够，模型需要白色锚点）：`以画面中的[白墙/白色格架/白纸]为白点基准，还原为不带任何黄调的纯净白，整体呈中性标准光环境`
- **杂物清理**：`移除[位置]的[杂物]，背景自然补全`
- **混合光源**：`画面存在[暖色室内灯与冷色窗光]混合光源，统一为[以窗光为主的自然色温]`
- **反光眩光**：`消除[位置]的玻璃反光/镜头眩光，恢复该区域细节`
- **人像**：`人物肤色还原自然通透，不改变五官、体型和表情`
- **夜景**：`压暗过曝的灯牌和光源，提亮环境暗部，保持夜晚氛围不要变成白天`
- **翻拍屏幕/纸面**：`去除摩尔纹和反光，页面拉平为正视角，文字保持清晰锐利`

## 一次到位还是分轮

问题不超过 3 类 → 合并成一条指令直接跑。问题多、或几何调整幅度大（大角度矫正 + 大幅裁切）→ 建议分两轮并把两轮指令都给出：第一轮做几何（矫正、裁切、清杂物），第二轮做影调（曝光、色彩、清晰度）。几何变化大时一起做容易让模型重绘出错。
