## 二、三条执行原则

### 1. 走分支，`main` 不动

两个 symlink 都指向仓库根。改 `main` 会同时打断 Claude Code 和 Codex 上的 skill。

```
main   ← 保持现状，skill 继续可用
  └── app   ← A0/A1 全部在这里做，A1 跑通后再合并
```

### 2. SKILL.md 现在不删，只标记

"SKILL.md 彻底并进 App" 这个决定不变，但**执行时机后移到 A1 之后**。

理由：A0 删掉它，你立刻失去唯一能用的工具，而 App 至少还要几周才能用。A0 只在文件顶部加一段下线说明。

### 3. 下线的是调度器，不是知识

必须区分两类文件：

| 文件 | 性质 | 去向 |
|---|---|---|
| `SKILL.md` | **调度器**——判断 A/B/C 模式、编排流程 | A1 后删除，其职责由 App 的 UI 承担 |
| `references/*.md` | **知识**——设计风格库、模型规范、修图模板 | 永久保留，改名 `knowledge/` |

`references/` 里的内容是分析 prompt 和编译适配器的人类可读源头，不能跟着 SKILL.md 一起下线。

## 八、执行偏离记录

原方案有三处判断在动手时被证伪，如实记录。

### 1. `git checkout` 不成立，改用 git worktree

原方案写"在 `app` 分支做改造，`main` 不动所以两个 skill 软链不受影响"。**这是错的**——
`git checkout` 换的是同一个工作目录的内容，切到 `app` 的那一刻软链看到的就是 app 分支的文件。

改用 `git worktree add ../image2prompt-app app`：app 分支拿到独立工作目录，
原目录永远停在 `main`，软链全程不受影响。已验证 `~/.claude/skills/image2prompt/SKILL.md` 仍在。

### 2. Swift target 拆成库 + 可执行两个

原方案画的是单个 `Sources/Image2Prompt/`。实际拆成：

```
Sources/Image2PromptCore/   ← 库：StyleSpec / Compile / Lint / Drift，可被测试
Sources/Image2Prompt/       ← 可执行：只有 @main 和 UI
```

原因：带 `@main` 的可执行 target 做 `@testable import` 会撞链接问题，
而 A1/A2 要往 Core 移植约 1272 行逻辑和 43 个测试用例，可测性是硬要求。

### 3. XCTest 用不了，改用 swift-testing

**XCTest.framework 随 Xcode 走，Command Line Tools 里没有**——`import XCTest` 直接报
`no such module`。这本来会让"不装 Xcode 也能开发"的前提破产。

实测 swift-testing（`import Testing`）随 Swift 工具链走，无 Xcode 可用：

```
✔ Test run with 2 tests passed after 0.001 seconds.
```

所以 43 个用例的移植不必等装 Xcode。移植时用 `@Test` + `#expect`，不用 `XCTAssert`。

### 4. 改名落地：bundle id 不只是个标识符

定名之后替换占位名，发现原方案把改名当成了纯文本替换，实际不是：**bundle id 同时是
Application Support 下的数据目录名和 Keychain 的 service 名**。直接改，已经存下来的
`library.sqlite`（49 KB 库 + 94 KB 未 checkpoint 的 WAL）会静默失联——App 照常启动，
库是空的，最坏的一种故障形态。

处理方式：

- 三处名字收进 `FormlessCore/AppIdentity.swift` 单点定义，字符串只出现一次；
- `Store.migrateFromLegacyDirectory` 在新目录无库、老目录有库时搬一次，`.sqlite` /
  `-wal` / `-shm` 三个文件一起搬（只搬主文件会丢掉未 checkpoint 的写入）；
- `Keychain.get` 读不到就回退到老 service，读到顺手写回新的；
- `AppIdentityTests` 真的去读 `Scripts/bundle.sh`，校验脚本里的三个名字和 Swift 常量一致——
  这两份对不上不会编译报错，只会让数据消失。

Swift 模块名同时从 `Image2Prompt*` 改为 `Formless*`（目录 `git mv`，`import` 全量替换）。
趁代码量小做掉，晚做只会更贵。`swift test` 73 passed。
