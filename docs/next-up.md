## 一笔要记下的技术债

**v0.1 → v0.2 没有升级路径。** `validate.ts` 已经硬切到 v0.2，Swift 侧 decode 的新字段
（`source.width/height/aspect_exact`、`content.carrier_type`、`on_image_text[].ocr_status`、
`composition.panel_count`）全是非可选的。任何 v0.1 时期的 spec 现在校验不过、decode 不出来，
而 `Store` 那条读取路径是 `try?` ——**失败是静默的**，那条目会显示成没分析过。

目前实际影响为零（本地库里 2 条 spec 都已是 0.2，仓库四份 fixture 也是）。但第 1 步会产出
一批要长期留存的 spec，动手前先定一件事：

- **每次升 schema 就重跑**——现在成本最低（一张 2.5 分钟），但每升一版就要重跑全库；
- **写升级器**——一次性成本高，全库规模上去之后才划算。

现在选前者，但要在这里写下来，别到了几百张的时候才想起来没有退路。
